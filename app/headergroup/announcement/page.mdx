# Announcement bar

The **Announcement Bar** is a full-width promotional strip positioned at the very top of your store. It's perfect for sharing important messages, sales, free shipping offers, or any short call-to-action.

You can choose between a **static message** or a **ticker** (marquee) that automatically scrolls to attract attention. The bar inherits your store's active color scheme but also allows custom colors for a unique look.

![Announcement Bar Settings in Theme Editor](/img/announcement.png)

---

## Overview

The Announcement Bar is part of the **header group** and appears above the main header on all pages. It includes:

- **Message** – Rich text with optional formatting (bold, italic, links).
- **Icon** – Choose from 17 built‑in icons (including gift, star, shipping, discount).
- **Ticker mode** – Turn your message into a continuous scrolling marquee.
- **Height control** – Separate values for desktop and mobile.
- **Typography** – Adjust font size, weight, style, and text transform.
- **Color Scheme** – Use the global Light / Dark / Light+Accent schemes or override with custom colors.
- **Borders** – Enable/disable top and bottom borders with custom color.
- **Custom CSS** – Add your own styles for further flexibility.

All settings are available directly in the Shopify Theme Editor – no code required.

## How It Works

### Static vs Ticker Mode

- **Static mode** – The message is displayed as a single line (or wrapped) and stays still. If a link is set, the entire bar becomes clickable.
- **Ticker mode** – The text is duplicated and animated to scroll horizontally. The speed setting controls how fast it moves. Hovering over the ticker pauses the animation for better readability.

### Icon Placement

When an icon is selected, it appears directly before the text, aligned vertically. In ticker mode, the icon scrolls along with the text.

### Responsive Behavior

- On **desktop**, the bar uses the `height_desktop` value.
- On **mobile**, it switches to `height_mobile` for a more compact appearance.
- The text alignment and typography settings are applied uniformly across all devices.

### Color Scheme Integration

The Announcement Bar uses the same Color Scheme system as the rest of the COSME theme. By default, it respects the selected scheme's background and text colors. If you enable `Use custom colors`, you can bypass the scheme and set your own background and text colors. This is useful for highlighting seasonal promotions or urgent messages.

## Accessibility

The Announcement Bar is built with accessibility in mind:

- **Semantic HTML** – Uses `<aside>` for landmark role.
- **Keyboard navigation** – If the bar contains a link, it is focusable and displays a `:focus-visible` ring.
- **Screen readers** – The optional `Link label` provides an accessible name for the link.
- **Reduced motion** – The ticker animation respects `prefers-reduced-motion` and the global `enable_animations` setting (if animations are disabled, the ticker stops).
- **Contrast** – Colors are derived from your chosen scheme or custom picker; ensure sufficient contrast for readability.

## Customization Tips

- **Add new icons** – Extend the `icon` select list in the schema and add the corresponding SVG file to `assets/icon-{name}.svg`.
- **Change ticker speed** – Adjust the `speed` range (min/max) in the schema to allow faster or slower scrolling.
- **Override spacing** – Use the **Custom CSS** field to fine‑tune padding or margins without touching the theme code.

## Troubleshooting

### The ticker is not moving

- Ensure `Enable ticker` is checked.
- Check that `Speed` is not set too high (high values slow down the animation).
- If `enable_animations` is off globally or `prefers-reduced-motion` is active, the ticker will be disabled.

### The icon is not showing

- Confirm that you selected an icon from the dropdown.
- Verify that the corresponding SVG file exists in `assets/` (e.g., `icon-gift.svg`).

### The bar does not appear

- Make sure `Show announcement` is checked and the `Message` field is not empty.
- The bar is part of the header group; ensure it is added to the `header-group` in your theme's section groups.
