# Editorial Media Hero

The **Editorial Media Hero** is a universal hero component that adapts to four distinct editorial layouts. Unlike the classic [Hero](/homegroup/hero), this section is designed to be reused across different theme presets — beauty, grooming, fashion, and jewelry — with radically different visual outcomes from the same code.

Each layout is a curated preset in itself:

- **Fullscreen** — immersive campaign hero with a single large visual
- **Large** — editorial banner with reduced height
- **Split** — two-column composition (media + text)
- **Grid Carousel** — horizontal editorial gallery with seamless infinite loop

The section is available in **Add section → Editorial Media Hero** and is not automatically added to any preset. Use it in Faro, Facet, or any custom setup without touching Cosme's original Hero.

![Editorial Media Hero in Theme Editor](/img/editorial-media-hero-admin.png)

---

## Overview

The Editorial Media Hero is a full‑width, block-based section with:

- **Four layout modes** — Fullscreen, Large, Split, Grid Carousel — selectable via a single setting
- **Slide blocks** — up to 8 slides per section, each independently configurable
- **Image or Video per slide** — native Shopify video picker, no apps, no external embeds
- **Per-slide content color** — Auto, Light, or Dark, for readable text over any imagery
- **Per-slide alignment** — override the section-level alignment per slide (Fullscreen and Large only)
- **Slider controls** — dots, counter (`01 / 06`), arrows, autoplay
- **Seamless infinite loop** — in Grid Carousel, slides wrap continuously without a rewind
- **Controls color** — force light or dark controls when sitting over media
- **Section width** — Full (edge-to-edge) or Page (constrained)
- **Full color scheme integration** — every visual inherits from the selected COSME scheme

All settings and content are editable in the Shopify Theme Editor — no code required.

## Slider Behaviour

### Autoplay

- Advances slides at the configured interval
- Disabled when: only one slide, `enable_animations` is off, or `prefers-reduced-motion` is active
- **Pauses** when the section is off-screen (IntersectionObserver)
- **Pauses** on focus, hover
- **Resumes** after user interaction timeout

### Seamless Infinite Loop (Grid Carousel only)

The Grid Carousel uses a **clone + snap** technique:

- Real slides are rendered between lead clones (last N) and tail clones (first N), where N = maximum visible items
- When the user scrolls into a clone zone, the viewport scrolls back by exactly one cycle width — visually identical, imperceptible
- Uses `scrollend` event in modern browsers, falls back to a debounced scroll timer
- Videos inside clones are never hydrated or played

### Manual Controls

- **Dots** — jump directly to a slide
- **Arrows** — move one slide at a time
- **Keyboard** — when focus is inside the section, `ArrowLeft` / `ArrowRight` navigate
- **Touch** — native horizontal swipe with momentum, snap to panel edges
- Autoplay resets when the user interacts manually

### Transitions

- Fullscreen / Large / Split: **subtle opacity fade** between slides
- Grid Carousel: **no cross-fade** between panels — native scroll-snap motion
- All transitions respect `prefers-reduced-motion`

---

## Video Behaviour

- Videos autoplay **muted** and **looped**, with `playsinline` for iOS
- First slide loads `eager`, others `lazy`
- Videos hydrate only when their slide becomes active or visible
- When a slide becomes inactive, its video **pauses and resets** to frame 0
- Mobile-specific video overrides desktop video below 750px
- If a video fails to load, its poster image is used as fallback

<Callout type="info">
  Browsers block autoplay with sound. The section always sets `muted=true` and `playsinline` — no way to autoplay audio, and this is expected.
</Callout>

## Color Scheme Integration

The selected scheme affects:

- Section background (visible in Split and Grid)
- Heading, body text, eyebrow
- Overlay tint over media
- Controls (arrows, dots, counter)
- Button styling (via `cosme-button`)
- Placeholder SVG (auto-inverts on dark backgrounds)

### Per-Slide Content Color

Each slide can override its own text color:

- **Auto** — inherits from the color scheme (default)
- **Light** — soft off-white text; useful over dark imagery
- **Dark** — soft ink text; useful over light imagery

This applies to eyebrow, heading, and text. Buttons keep the color scheme styling.

### Controls Color

When the controls sit over media (Fullscreen and Large), the **Controls color** setting forces:

- **Auto** — uses `--color-slider-arrows` from the color scheme
- **Light** — light arrows, dots, counter
- **Dark** — dark arrows, dots, counter

In Split and Grid, controls sit on the section background and always use the scheme — the setting is hidden.

## Performance

- **First slide image**: `loading="eager"` + `fetchpriority="high"` for fast LCP
- **Subsequent slides**: `loading="lazy"`
- **Videos**: `preload="none"` until the slide is activated
- **Responsive images**: `cosme-image` snippet generates `srcset` and `sizes` per layout
- **Grid clones**: images are marked `lazy`, videos never hydrate
- **No external dependencies**: pure Liquid + vanilla JavaScript

---

## Accessibility

- **Semantic HTML**: `<section>`, `<article>`, `<nav>`, `<button>`
- **ARIA**: `aria-roledescription="carousel"`, `role="group"`, `aria-live="polite"` for slide changes
- **Keyboard navigation**: Arrow keys when focused; all controls reachable by Tab
- **Focus management**: focus returns to the triggering control after closing lightbox-like overlays
- **Reduced motion**: all animation and autoplay disabled when `prefers-reduced-motion` is set
- **Clone slides**: `aria-hidden="true"` and `inert` — never reachable by keyboard or screen reader
- **Contrast**: text over media is protected by the overlay opacity setting

## Customization Tips

- **Change layout per use case** — one section covers four very different visual styles. No need to add a new section for each preset.
- **Use video on the first slide** — the first slide loads eagerly and hydrates the video instantly. Great for hero campaign videos.
- **Per-slide alignment is powerful** — in Fullscreen, put text on the left for one slide and right for the next if the composition of the image demands it.
- **Content color per slide** — useful when your slide images alternate between dark and light backgrounds.
- **Grid Carousel scales with content** — add 4 or 12 slides; the seamless loop handles any count.
- **Controls color** — if your imagery is unpredictable, set Controls color to Light to guarantee visibility.
- **Grid gap** — small gaps make panels read as a unified composition; large gaps make each panel feel isolated.

## Troubleshooting

### Grid Carousel jumps back to the start

The seamless loop requires real slides to be present. If the carousel wraps by scrolling all the way back, check that:

- There are at least 2 slides
- Your browser supports `scrollend` (Chrome 114+, Safari 16.4+, Firefox 109+)
- JavaScript is enabled and no errors appear in the console

### Videos don't autoplay

- Confirm `Autoplay` is enabled in the section settings
- Browser autoplay policies require `muted` — the section handles this automatically
- Check that the video is uploaded in Shopify's native video picker, not embedded from YouTube or Vimeo
- Reduced-motion OS settings will disable autoplay (this is intentional)

### Text is invisible over dark media

- Set **Content color** on that slide to **Light**
- Or increase **Overlay opacity** to 40–50%
- Or change the section **Color scheme** to a dark one and set Content color to Auto

### Grid Carousel shows "peek" but panels look cramped

- Reduce **Desktop visible items** from 3 to 2
- Or increase **Grid gap** to Large

### Arrows or dots are hard to see

- Set **Controls color** to Light or Dark depending on your media
- In Fullscreen and Large this overrides the scheme-based color

### Split layout on mobile looks like a stack

This is expected. Split layout collapses to a single column below 990px to preserve readability.
