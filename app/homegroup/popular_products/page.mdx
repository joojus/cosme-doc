# Popular Products

The **Popular Products** section displays a grid of products from a selected Shopify collection (or demo products) in an editorial layout. It’s designed for beauty and lifestyle brands to showcase best‑selling or curated items with a clean, minimal aesthetic.

Each product card supports hover‑revealed secondary images, Quick View, and AJAX Add to Cart, and the grid can be paginated with Previous/Next buttons when there are more products than columns.

![Popular Products in Theme Editor](/img/popular-products.png)

---

## Overview

The Popular Products section is a full‑width, editorial‑style product grid that typically sits below the Hero or between other content sections. It includes:

- **Product grid** – Responsive columns (3–5 on desktop, 1–2 on mobile) with flexible gap.
- **Collection selection** – Choose any Shopify collection; falls back to demo products if none selected.
- **Product cards** – Powered by the `cosme-product-card` snippet, with full support for:
  - Secondary image on hover (cross‑fade)
  - Quick View button (with global Quick View modal)
  - AJAX Add to Cart (for single‑variant products)
  - Product badges (Sale, Sold Out)
  - Vendor, price, and title display
- **Pagination** – Previous/Next navigation (when enabled) that pages through the product list, showing one “page” equal to the number of desktop columns.
- **Demo data** – Pre‑populated with 8 realistic beauty products, so the section looks complete immediately after installation.
- **Color Schemes** – Inherits from global Light / Dark / Light+Accent with a dedicated scheme picker.
- **Flexible controls** – Toggle vendor, price, badges, secondary image, Quick View, Add to Cart, and navigation independently.
- **Responsive** – Optimised for desktop, tablet, and mobile.

All settings are available directly in the Shopify Theme Editor – no code required.

## Visual Layout

### Desktop (≥990px)

- Products are arranged in a grid with the chosen number of columns (3, 4, or 5).
- The heading and optional eyebrow sit on the left; the navigation buttons (Previous/Next) sit on the right.
- Product cards display the image, title, vendor (if enabled), and price.
- Hover reveals secondary image (if available) and slides out action buttons (Quick View, Add to Cart) from the bottom‑right corner (on devices with fine pointer).

### Tablet (768px – 989px)

- The grid adapts to a maximum of 3 columns (even if desktop columns are set to 4 or 5).
- Navigation buttons remain visible if there are more products than the current columns.

### Mobile (768px)

- The grid uses 1 or 2 columns (as set in `mobile_columns`).
- The heading and navigation stack vertically, with navigation aligned to the right.
- Action buttons are always visible (no hover‑reveal), and the secondary image cross‑fade is disabled on touch devices.

## Pagination Behaviour

When **Show navigation** is enabled and the number of products exceeds the number of visible columns (on desktop), the section activates a pagination system:

- **Pages** – Each page shows exactly the number of products that fit in one row (equal to `desktop_columns` or the current effective columns on tablet).
- **Previous / Next buttons** – Clicking moves one page forward or backward.
- **Disabled state** – Buttons are disabled when on the first or last page.
- **Live region** – A hidden live region announces the current page number (e.g., “Page 1 of 3”) to screen readers.
- **Responsive** – On resize, pagination recalculates; if the columns change, the current page resets to the first page to avoid empty states.
- **No pagination** – When products fit in one row (or navigation is off), the buttons are hidden and all products are shown in a single grid.

## Color Scheme Integration

The section uses the global color scheme system. The selected scheme affects:

- **Section background** (uses `--color-background`).
- **Text colours** – heading, body text, muted text (vendor, price) use the scheme’s `--color-foreground`, `--color-heading`, `--color-muted`.
- **Badges and buttons** – inherit accent and border colours from the scheme.

The scheme can be changed independently of other sections, giving you flexibility to create contrast or harmony across the page.

## Accessibility

The Popular Products section is built with accessibility as a priority:

- **Semantic HTML** – Uses `<section>`, `<article>` for each product card, proper heading hierarchy (`<h2>` for section heading).
- **ARIA attributes** – The section has `aria-label` derived from translations; the navigation buttons have `aria-label` for Previous/Next; the live region announces page changes.
- **Keyboard navigation** – All interactive elements (buttons, links, form submit) are focusable and have visible `:focus-visible` rings.
- **Focus management** – Focus is properly handled; after Quick View or Add to Cart interactions, focus returns to the triggering element.
- **Reduced motion** – All animations respect `prefers-reduced-motion`; transitions are disabled when reduced motion is preferred.
- **Image alt text** – Product images use the product title as alt text; secondary images have empty alt (decorative).

## Customization Tips

- **Change product source** – Select a real collection in the Theme Editor; the demo data will be replaced automatically.
- **Adjust columns** – Choose 3, 4, or 5 desktop columns; the grid will reflow and pagination recalculates.
- **Toggle features** – Turn off vendor, price, badges, secondary image, Quick View, or Add to Cart to simplify the card.
- **Hide navigation** – If you prefer a static grid without pagination, turn off `Show navigation` – all products will be shown in one long grid.
- **Customise the heading** – The `Heading` and `Eyebrow` are fully editable. Use them to match your brand voice (e.g., “Bestsellers”, “New Arrivals”).
- **Override colours** – The section uses the selected color scheme; you can change it per section to create visual separation.

## Troubleshooting

### Products are not showing

- Ensure you have selected a collection that contains products.
- If no collection is selected, demo products will appear – check that `products_to_show` is set to a value > 0.
- Verify that the products are published and available in your store.

### Navigation buttons do not appear

- Check that `Show navigation` is enabled.
- Navigation only appears when the number of products exceeds the visible columns (e.g., 8 products with 4 columns = 2 pages, so buttons show).
- On tablet, columns are capped at 3; if products ≤ 3, navigation is hidden.

### Secondary image does not show on hover

- Ensure `Show secondary image` is enabled.
- The product must have at least two images in its media (the second image is used).
- On touch devices (mobile/tablet), hover effects are disabled; secondary image will not show.

### Quick View or Add to Cart buttons are missing

- Check that the corresponding toggles are enabled in section settings.
- For Add to Cart: it only appears for products with exactly one variant (i.e., `has_only_default_variant`). Products with multiple variants will not show the Add to Cart button (they should use Quick View instead).

### Pagination does not update after resizing

- The section listens to `resize` events and recalculates. If you experience issues, ensure you are using the latest version of the JavaScript.
- If the browser window is resized, the current page resets to the first page.
