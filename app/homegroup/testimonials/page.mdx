# Testimonials

The **Testimonials** section presents customer feedback in a refined, editorial carousel. It is designed for beauty and lifestyle brands that want to build trust through authentic, human‑centred reviews without relying on third‑party review apps.

The section features a horizontal carousel with a subtle peek of the next card, optional rating summary, individual star ratings, author avatars, verified badges, and optional product references. Every testimonial is managed manually through Theme Editor blocks, giving merchants full control over the content.

![Testimonials in action](/img/testimonials-main.png)

---

## Overview

The Testimonials section is a full‑width, editorial‑style carousel that typically sits lower on the homepage, providing a visual pause after more dynamic sections like Hero or Vertical Video. It includes:

- **Editorial header** – eyebrow, heading, and optional descriptive text.
- **Rating summary** – compact score, stars, and review count (optional).
- **Testimonial cards** – quotes, author name, location, avatar, role, and star rating.
- **Verified badge** – optional label to indicate verified customers.
- **Product reference** – optional link to a product with image, title, and price.
- **Quick View** – plus button on product references opens the global Quick View modal.
- **Horizontal carousel** – smooth, native scrolling with arrows and optional autoplay.
- **Three colour schemes** – Light, Dark, Light+Accent, fully integrated with the global colour system.
- **Fully responsive** – adapts to desktop, tablet, and mobile with native touch scrolling.

All settings are available directly in the Shopify Theme Editor – no code required.

## Visual Layout

### Desktop (≥990px)

- The header and optional rating summary sit at the top.
- The carousel shows the number of cards set in **Desktop cards** (2, 3, or 4).
- The next card is partially visible (approximately 18% peek) to indicate more content.
- Cards have a consistent minimum height; long quotes are clamped at 8 lines.
- Arrow buttons appear on the sides when there is overflow.

### Tablet (750–989px)

- The carousel shows 1 or 2 cards (as set in **Tablet cards**).
- The next card is partially visible.
- Arrow buttons remain functional.

### Mobile (750px)

- The carousel shows 1 card with a partial peek of the next card.
- Touch scrolling works natively.
- Arrow buttons are slightly smaller but remain touch‑friendly (44px minimum).

## Carousel & Autoplay Behaviour

### Native Scrolling

- The carousel uses native horizontal scrolling with `scroll-snap-type: x proximity` for smooth, natural touch interaction.
- Cards snap into place when scrolling stops, but the snap is not aggressive – users can stop mid‑scroll.
- Arrow buttons move the carousel by one “card group” (the number of visible cards).

### Autoplay

- **Autoplay is disabled by default** – merchants must explicitly enable it.
- When enabled, the carousel advances automatically at the chosen interval.
- Autoplay pauses when:
  - The user clicks an arrow button.
  - The user scrolls the carousel manually.
  - The user focuses any interactive element inside the section.
  - The section is not sufficiently visible (intersection ratio < 35%).
  - The browser tab is hidden.
  - `prefers-reduced-motion` is active.
  - Global `enable_animations` is disabled.
- Autoplay resumes after a short idle period, provided the section is still visible and autoplay is still allowed.

### Arrows

- Left/right chevron buttons are shown only when there is overflow (more cards than visible).
- Buttons are disabled at the start/end of the carousel.
- Each click moves the carousel by one card group.

## Accessibility

The Testimonials section is built with accessibility as a priority:

- **Semantic HTML** – uses `<section>`, `<h2>`, `<article>`, `<blockquote>`, `<ul>`, `<li>` appropriately.
- **Heading hierarchy** – the section heading is an `<h2>`; author names are not headings.
- **Star ratings** – each rating has a visually hidden text equivalent (e.g., “5 out of 5 stars”).
- **Avatar alt text** – uses the author name when available; otherwise a generic fallback.
- **Keyboard navigation** – all interactive elements (arrows, product links, Quick View buttons) are focusable and have visible `:focus-visible` rings.
- **No focus trap** – keyboard focus moves naturally through the page.
- **Reduced motion** – autoplay and smooth scrolling are disabled when `prefers-reduced-motion` is active.
- **Touch targets** – all buttons are at least 44px for easy interaction on mobile.

## Performance

- The carousel uses native scrolling – no third‑party libraries.
- JavaScript is lightweight, using `IntersectionObserver` for visibility checks and `ResizeObserver` for responsive updates.
- Autoplay pauses when the section is not visible or when the tab is hidden.
- Cards have a minimum height to prevent layout shift when avatars or products are missing.
- Images (avatars, product thumbnails) use `loading="lazy"`.
- Events are cleaned up when the section is removed (`shopify:section:unload`).

## Customization Tips

- **Adjust card count** – change **Desktop cards** and **Tablet cards** to control how many testimonials are visible at once.
- **Disable rating summary** – turn off **Show rating summary** for a cleaner header.
- **Add avatars** – upload customer photos for a more personal feel; the fallback initials work well for minimal branding.
- **Enable product references** – select products and turn on **Show product** to link testimonials to specific items.
- **Use Quick View** – the plus button on product references opens the global Quick View modal, allowing customers to preview products without leaving the page.
- **Enable autoplay** – turn on **Autoplay** for a dynamic, self‑playing carousel (useful for hero‑style placements).
- **Adjust verified badge** – the badge is useful for building trust; consider enabling it for your real testimonials.

## Troubleshooting

### Testimonial card does not appear

- Ensure the **Quote** field is not empty – it is required to render the card.
- Check that the block is not disabled or deleted.

### Arrows are hidden

- Arrows only appear when there are more testimonials than can fit in the viewport (overflow).
- If **Show arrows** is disabled in settings, arrows are hidden regardless of overflow.

### Autoplay does not work

- Autoplay is **disabled by default** – enable it in the section settings.
- Check that **Autoplay** is `true` and **Autoplay interval** is set.
- If `prefers-reduced-motion` is active, autoplay will not run.
- If the global `enable_animations` setting is `false`, autoplay will not run.
- Autoplay pauses when the section is not sufficiently visible (intersection ratio < 35%).

### Stars are not displaying correctly

- The star system uses the existing `cosme-icon` for the `star` icon. Ensure the icon asset exists.
- If stars appear empty, check that the `--star-fill` CSS variable is being applied correctly.
- For individual testimonial ratings, the value must be between 1 and 5 (step 1).

### Product reference does not show

- Ensure a product is selected in the block settings.
- Ensure **Show product** is checked.
- If the product is unpublished or out of stock, the reference may not render.

### Quick View does not open

- Ensure the global Quick View modal is enabled in Theme Settings (`quick_view_enabled`).
- Check that the product has a valid handle and URL.
- Look for JavaScript errors in the browser console.
