# Editorial CTA

The **Editorial CTA** section is a premium promotional block designed for the lower part of the homepage, positioned between the main content and the footer. It combines a large editorial image with compelling copy and calls to action, creating a refined, brand‑focused narrative that drives conversions without feeling like a standard Shopify banner.

The section offers flexible layout options: image‑led (left or right), or a text‑only mode with full‑width copy aligned left, center, or right. It integrates seamlessly with the COSME design system, inheriting colour schemes, typography, spacing, and component styles.

![Editorial CTA in action](/img/editorial-cta.png)

---

## Overview

The Editorial CTA section is a full‑width, editorial‑style promotional block that typically sits near the bottom of the homepage, just before the Benefits / Trust Bar. It includes:

- **Editorial composition** – a large image paired with thoughtfully spaced copy.
- **Flexible layout** – image left / content right, content left / image right, or text‑only.
- **Rich copy options** – eyebrow, heading, description, and two call‑to‑action buttons.
- **Image management** – desktop and mobile images, fit (contain/cover), focal point, and optional link.
- **Background control** – choose between `--color-background` and `--color-background-2`.
- **Subtle animation** – optional reveal on scroll, respecting reduced motion.
- **Three colour schemes** – Light, Dark, Light+Accent, fully integrated with the global colour system.
- **Fully responsive** – adapts to desktop, tablet, and mobile with consistent spacing and typography.

All settings are available directly in the Shopify Theme Editor – no code required.

## Visual Layout

### Desktop (≥990px)

- The image and content sit side by side in a two‑column grid.
- The image column width is adjustable (40–70%).
- The content has a maximum width (content_width) and is vertically aligned as chosen (top/center/bottom).
- Typography is large and editorial; the heading is capped at 14 characters (1–2 lines) for maximum impact.
- A subtle reveal animation (opacity + translateY) is applied on scroll (when enabled).

### Tablet (750–989px)

- The two‑column grid is maintained with slightly reduced spacing.
- Heading size is reduced proportionally.
- Padding and gaps are optimised for the smaller screen.

### Mobile (750px)

- The image and content stack vertically (image above content, or content above image depending on layout).
- The image height is capped (max-height: 46vh or 22rem) to avoid excessive scrolling.
- The heading wraps naturally without a character limit.
- Buttons stack if needed and remain touch‑friendly.
- In `Text only` mode, the copy spans the full width and is aligned as chosen.

## Accessibility

The Editorial CTA section is built with accessibility as a priority:

- **Semantic HTML** – uses `<section>`, `<h2>`, `<p>` appropriately; the image link is keyboard‑accessible.
- **Heading hierarchy** – the main heading is an `<h2>`; the eyebrow is a `<p>`.
- **Image alt text** – uses the image’s `alt` attribute, or falls back to the section heading.
- **Placeholder handling** – when no image is set, a placeholder SVG is given an appropriate `role` and `aria-label` (or `aria-hidden` when purely decorative).
- **Keyboard navigation** – all interactive elements (buttons, image link) are focusable and have visible `:focus-visible` rings.
- **Reduced motion** – the reveal animation respects `prefers-reduced-motion` and the global `enable_animations` setting.
- **Contrast** – all text uses scheme‑appropriate colour tokens (e.g., `--color-heading`, `--color-muted`, `--color-foreground`).

## Performance

- No JavaScript is used in this section – all interactivity is handled by native HTML/CSS.
- Images are lazy‑loaded (via `loading="lazy"`) and optimised with responsive `srcset` and `sizes`.
- The mobile image is conditionally loaded via `<picture>` with a `source` element, reducing bandwidth on small screens.
- CSS is scoped to the section using BEM‑style classes and `{% stylesheet %}`.
- The section uses existing COSME variables and components (`cosme-image`, `cosme-button`), avoiding duplication.

## Customization Tips

- **Adjust image width** – use the **Image width** slider to give the image more or less prominence.
- **Switch image fit** – `Cover` is ideal for full‑bleed editorial looks; `Contain` works well when you need to show the entire image.
- **Hide the image** – choose the **Text only** layout to create a simple, typographic promotion.
- **Change background** – switch **Background style** to `Alternate` to create visual separation from the previous section.
- **Add a border** – enable **Show border** for a subtle divider between sections.
- **Refine spacing** – use **Section spacing** (Small/Medium/Large) to control vertical rhythm.
- **Use the image link** – make the entire image clickable to drive traffic to a collection or product page.
- **Test different content widths** – adjust the **Content width** to control how wide the text block appears.

## Troubleshooting

### Image does not appear

- Ensure an image is selected in the **Image** picker.
- If using `Cover` fit, check that the image has sufficient resolution and that the focal point is set correctly.
- On mobile, if the **Mobile image** is empty, the desktop image is used as a fallback.

### Buttons are not aligned as expected

- In **Text only** mode, use the **Text alignment** setting to control horizontal alignment (left/center/right).
- In layout with image, buttons inherit the content alignment (top/center/bottom) but remain left‑aligned relative to the text block.

### Section height seems too large

- Change **Section height** to `Auto` to let the content determine the height, or reduce it to `Medium`.
- Check that **Section spacing** is not set to `Large`.

### Background colour does not change

- Verify that the **Background style** is set to `Alternate` – this uses `--color-background-2`.
- The **Color scheme** must be selected correctly – Light/Dark/Light+Accent.

### Border is not visible

- Ensure **Show border** is checked.
- Adjust **Border width** if needed – the default is 1px, which may be subtle.

### Animation does not play

- The reveal animation is only active when global `enable_animations` is true and `prefers-reduced-motion` is not active.
- Check the **Theme Settings → Animation → Enable animations** toggle.
