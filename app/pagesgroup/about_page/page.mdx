# About Page

The **About Page** is the editorial brand story of the COSME theme. It presents the philosophy, values, and visual identity of a luxury beauty brand through a carefully composed sequence of sections — from a full‑width hero to a closing call‑to‑action. The page is designed to feel like a premium editorial magazine spread, not a generic Shopify About Us template.

The page is built as a custom template (`page.about.json`) composed of seven independent sections, each with its own Theme Editor settings. Merchants can create a standard Shopify page (e.g., `About`) and assign the `about` template.

---

## Overview

The About Page provides the following key features:

- **Editorial Hero** – full‑width hero with eyebrow, large headline, description, and a prominent image (desktop and mobile versions).
- **Brand Story** – asymmetric layout with image and copy; image position can be switched left/right.
- **Manifesto** – a typographic pause with a large statement and supporting text.
- **Philosophy** – editorial list of principles (3–6 items) with numbering and hairline dividers.
- **Image + Story** – visual composition with a primary image, optional secondary image, and copy.
- **Brand Facts** – optional row of facts (2–4 items) with oversized numbers and short descriptions.
- **Final CTA** – closing section with primary and secondary CTAs, optionally disable‑able.
- **Color schemes** – each section can have its own colour scheme (Light, Dark, Light+Accent).
- **Responsive** – adapts from desktop to tablet to mobile.
- **Accessibility** – semantic headings, focus states, reduced‑motion support.

All content is fully editable through the Theme Editor.

---

## How to Use

1. In Shopify Admin, go to **Online Store → Pages**.
2. Create a new page (e.g., `About`).
3. In the **Theme template** dropdown, select **`about`**.
4. Save the page.
5. Go to **Online Store → Themes → Customize**.
6. Select the **About** page from the dropdown at the top.
7. Configure each section’s content and settings via the Theme Editor.

## Visual Rhythm

The sections are sequenced to create a deliberate editorial flow:

1. **Hero** – opens with a strong visual and headline.
2. **Story** – introduces the brand narrative.
3. **Manifesto** – provides a typographic pause.
4. **Philosophy** – lists core principles.
5. **Image + Story** – returns to visual storytelling.
6. **Brand Facts** – optional, quiet factual layer.
7. **CTA** – closes the page with a clear action.

The transition between sections is smooth, with consistent spacing and colour‑scheme transitions.

## Accessibility

- **Semantic headings**: Each section uses a logical heading hierarchy (H1 for hero, H2 for subsequent sections).
- **Image alt text**: All images support custom alt text; secondary images default to decorative (`alt=""`, `aria-hidden="true"`).
- **Keyboard navigation**: All interactive elements (buttons, links) are focusable with visible focus states.
- **Reduced motion**: CSS animations respect `prefers-reduced-motion`.
- **Colour contrast**: All text meets WCAG contrast requirements across the three colour schemes.

---

## Performance

- **No JavaScript**: The About page is entirely CSS + Liquid; no client‑side JavaScript.
- **Lazy loading**: Images below the fold use `loading="lazy"`.
- **Responsive images**: Uses Shopify's `image_url` with appropriate `sizes`.
- **CSS scoped**: All styles are scoped to their respective sections; no global pollution.

## Troubleshooting

### The About template is not showing in the Theme Editor
- Ensure `templates/page.about.json` exists in the theme.
- Create a page in Shopify Admin and assign the `about` template.
- In Theme Editor, select the **About** page from the dropdown.

### Images are not displaying
- Check that images are uploaded in the Theme Editor.
- If using desktop/mobile separate images, ensure both are set.
- If no image is set, a placeholder appears (SVG in production, hint in editor).

### A section is not visible on the storefront
- Some sections have an **Enable section** checkbox (Brand Facts, Final CTA). Ensure it is checked.
- If a section has no content (e.g., empty heading or body), it may still render; check that required fields are filled.

### The secondary image in Image + Story overlaps the text
- This is a known layout nuance. Adjust the image aspect ratio or use the Theme Editor to reposition.
- Alternatively, disable the secondary image if it is not needed.

### The layout is broken on mobile
- All sections are responsive; mobile layouts are purpose‑built.
- If something appears broken, check that no custom CSS overrides the theme’s default styles.

### The colour scheme does not match the rest of the theme
- Each section has its own colour scheme setting. Ensure they are set consistently (e.g., all `scheme-1` for a uniform look, or intentionally varied).

## Usage Examples

### Full editorial About page
- Enable all sections.
- Use the default copy or customise it to match your brand.
- Set all colour schemes to `Light` for a consistent, clean look.

### Minimal About page (no facts, no CTA)
- Disable **Brand Facts** and **Final CTA**.
- Only Hero, Story, Manifesto, Philosophy, and Image+Story remain.

### Dark + Accent variation
- Set the hero, story, and image sections to `Dark`.
- Set Manifesto, Philosophy, and CTA to `Light+Accent` for contrast.

### Image‑heavy About
- Upload high‑quality primary and secondary images.
- Use `Adapt` ratio to preserve original image proportions.
- Disable secondary image if it clutters the layout.
