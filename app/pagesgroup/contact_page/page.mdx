# Contact Page

The **Contact Page** is a premium editorial contact experience for the COSME theme. It combines a native Shopify contact form with curated contact information, a compact FAQ preview, and a closing call‑to‑action — all within the brand's luxury beauty aesthetic. Merchants can manage all content through the Theme Editor without touching code.

The page is built as a custom section (`main-contact.liquid`) with a dedicated template (`page.contact.json`). It uses Shopify's native `{% form 'contact' %}` for submissions, so no third‑party apps or external services are required.

![Contact Page example](/img/contact.png)

---

## Overview

The Contact Page provides the following key features:

- **Editorial hero** – configurable eyebrow, heading, description, alignment, and spacing.
- **Two‑column layout** – contact details (left) and the contact form (right) on desktop; stacks on mobile.
- **Contact information** – editable email, business hours, and optional phone with proper `mailto:` / `tel:` links.
- **Native Shopify contact form** – fields for Name, Email, optional Phone, and Message with success/error states.
- **Quick Answers** – optional FAQ preview with a compact accordion (up to 8 items), reusable from the Contact section blocks.
- **“View all FAQs” link** – configurable link to the full FAQ page.
- **Final editorial CTA** – optional closing section with eyebrow, heading, description, and a button (can link to the form itself or an external page).
- **Color schemes** – each main section (hero, FAQ, CTA) can have its own colour scheme.
- **Accessibility** – proper heading hierarchy, form labels, focus states, error/success announcements, reduced‑motion support.
- **Responsive** – adapts from desktop to tablet to mobile with touch‑friendly targets.

---

## How to Use

1. In Shopify Admin, go to **Online Store → Pages**.
2. Create a new page (e.g., `Contact`).
3. In the **Theme template** dropdown, select **`contact`**.
4. Save the page.
5. Go to **Online Store → Themes → Customize**.
6. Select the **Contact** page from the dropdown at the top.
7. Configure all content, form settings, FAQ blocks, and CTA via the Theme Editor.

## Visual Layout

### Desktop (≥990px)

- **Hero**: centred or left‑aligned with generous spacing.
- **Two‑column layout** (when contact info is shown):
  - **Left column (~38%)**: contact details with editorial spacing.
  - **Right column (~62%)**: form with labels, inputs, and submit button.
- **Quick Answers**: below the layout, centred or left‑aligned, with a compact accordion and “View all FAQs” link.
- **Final CTA**: full‑width, centred, with a button.

### Tablet (750–989px)

- The two‑column layout collapses to a single column (info first, form second).
- Spacing reduces appropriately.
- Submit button is full‑width.

### Mobile (750px)

- **Stacked**: hero → info → form → Quick Answers → CTA.
- **Form fields**: full‑width, touch‑friendly.
- **Accordion**: comfortable tap targets.
- **CTA button**: full‑width (up to `20rem`).

## Native Shopify Contact Form

The form is built with Shopify's native `{% form 'contact' %}`:

```liquid
{% form 'contact', id: form_id %}
  <!-- fields -->
{% endform %}

```
### Fields:

contact[name] – required

contact[email] – required, type="email"

contact[phone] – optional, configurable required

contact[body] – required, textarea

Success: when form.posted_successfully? is true, a success message appears (with role="status", tabindex="-1", autofocus).

Errors: if form.errors exists, an error block appears with links to each field (#ContactForm-...-field). Individual field errors are passed to cosme-form-field.

Validation: HTML5 validation is used (required, type="email"). Phone required is controlled by the phone_required setting.

The form submission is handled entirely by Shopify — no custom backend or third‑party service is involved.

## Accessibility

- **Heading hierarchy**: one `<h1>` for the hero; contact, form, FAQ, and CTA use `<h2>`.
- **Form labels**: all fields have explicit `<label>` elements with `for` attributes.
- **Error messages**: the error block uses `role="alert"` and `tabindex="-1"` with focus on render; field errors are displayed below each field.
- **Success message**: uses `role="status"` and `aria-live="polite"`.
- **Accordion**: keyboard‑accessible natively via `<details>`; focus rings visible.
- **Links**: `mailto:` and `tel:` are properly formed; custom links can override.
- **Focus states**: visible focus rings using `--color-accent`.
- **Reduced motion**: all transitions respect `prefers-reduced-motion`.

## Troubleshooting

### The contact form does not send messages
- Ensure the store has a valid email address configured in Shopify admin (**Settings → Store details → Contact email**).
- The form uses `{% form 'contact' %}` – it will not work if the store's email is not set.
- Check the network tab for any errors; the form submission is handled by Shopify.

### The success message does not appear after submission
- The success message appears only when `form.posted_successfully?` is true. After a successful submission, Shopify redirects to the same page with a `?contact_posted` parameter. The theme does not handle the redirect; it relies on Shopify's native behaviour.
- Ensure the `success_message` is set and the `<p>` with `role="status"` is correctly rendered.

### The error messages are not showing
- Errors are shown when `form.errors` is not empty. Each field error is passed to `cosme-form-field`. The error block also appears with a list of errors.
- If errors are not appearing, check that the `form.errors` object is correctly accessed.

### The Quick Answers accordion does not open
- The accordion uses native `<details>`/`<summary>`, so it works without JavaScript.
- If items do not open, ensure the markup is valid and no custom CSS is hiding the contents.
- The `open_by_default` setting opens the item via the `open` attribute.

### The “View all FAQs” link does not work
- The link defaults to `/pages/faq`. Ensure that the FAQ page exists and uses the `faq` template.
- You can change the link in Theme Editor (FAQ link setting).

### The final CTA button does nothing
- If the CTA link is empty or points to the current Contact page, the button scrolls to the contact form (via `#ContactForm-...`).
- If you want a different behaviour, set a custom URL in the CTA link setting.

### The phone field is required but not validating
- The phone field uses `required` only if `phone_required` is enabled. This is HTML5 validation; if you need server-side validation, Shopify's contact form does not support it for the phone field.
- Ensure the `phone_required` checkbox is checked.

### The layout is broken on mobile
- The section uses CSS Grid with `grid-template-columns: 1fr` on mobile and `1fr 1fr` on desktop. Check that no custom CSS overrides these rules.
- Make sure the `page-margin` variable is set correctly.

## Usage Examples

### Full featured Contact page (default)
- Enable all settings.
- Use the default hero, contact info, form, Quick Answers, and CTA.
- Set **FAQ color scheme** to `Light+Accent` for visual contrast.

### Minimal Contact page (no FAQ, no CTA)
- Disable **Enable Quick Answers** and **Show final CTA**.
- The page will show only the hero, contact info, and form.

### Business‑focused Contact page (with phone, hours)
- Fill in the **Phone** and **Phone label** fields.
- Set **Phone required** to `true` if needed.
- Adjust the business hours text.

### Dark scheme with accent CTA
- Set the main **Color scheme** to `Dark`.
- Set **CTA color scheme** to `Light+Accent` for a contrasting closing block.
