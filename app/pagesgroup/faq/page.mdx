# FAQ Page

The **FAQ Page** is a dedicated, editorial help center for the COSME theme. It transforms a standard Shopify page into a premium, interactive FAQ experience with search, category filtering, and a clean accordion layout. Designed for beauty and skincare brands, the page provides merchants with a flexible, block‑based system to manage questions and answers directly from the Theme Editor.

The page is built as a custom section (`main-faq.liquid`) that uses Shopify section blocks for individual FAQ items, native `<details>`/`<summary>` accordion, and client‑side filtering with zero external dependencies.

![FAQ Page example](/img/faq.png)

---

## Overview

The FAQ Page provides the following key features:

- **Editorial hero** – configurable eyebrow, heading, description, alignment, and spacing.
- **Two‑column desktop layout** – a sticky `QUESTIONS` label on the left, accordion on the right (optional single‑column mode available).
- **Accordion** – native `<details>`/`<summary>` with plus/minus icons, smooth height animation, and automatic close of previously opened items.
- **Search** – client‑side filtering of questions, answers, and categories with live result count and clear button.
- **Category navigation** – dynamic category buttons derived from FAQ block categories; combines with search.
- **FAQ blocks** – each block contains Question, Answer (rich text), Category, and Open‑by‑default toggle.
- **Optional note** – a subtle message below the FAQ list.
- **Contact CTA** – full‑width editorial band with eyebrow, heading, description, and a button linking to a contact page.
- **Color schemes** – main page and CTA each have independent colour scheme settings.
- **Accessibility** – keyboard‑friendly accordion, focus rings, reduced‑motion support, ARIA labels.

All FAQ content is managed entirely through Theme Editor blocks — no Shopify Page content is required.

---

## How to Use

1. In Shopify Admin, go to **Online Store → Pages**.
2. Create a new page (e.g., `FAQ`).
3. In the **Theme template** dropdown, select **`faq`**.
4. Save the page.
5. Go to **Online Store → Themes → Customize**.
6. Select the **FAQ** page from the dropdown at the top.
7. Add, remove, or reorder FAQ blocks; configure all settings as needed.

## Blocks

The FAQ section uses a single block type:

### FAQ Item Block

Each block represents one question and answer pair.

| Setting | Type | Default | Description |
|---------|------|---------|-------------|
| **Question** | Text | `How long does shipping take?` | The question text displayed in the accordion. |
| **Answer** | Richtext | `<p>Standard shipping typically arrives in 3–6 business days after dispatch.</p>` | The answer content (supports paragraphs, lists, links, etc.). |
| **Category** | Text | `Shipping` | The category label for the question (used for filtering). |
| **Open by default** | Checkbox | `false` | If enabled, this item will be open on page load (overrides `Open first` for this item). |

Merchants can add, remove, and reorder blocks freely. The block order determines the display order of FAQ items.

## Visual Layout

### Desktop (≥990px)

- **Two‑column layout** (when `Desktop columns = 2`):
  - **Left column**: sticky `QUESTIONS` label (position: sticky).
  - **Right column**: search, category navigation, FAQ accordion.
- **Single‑column layout** (when `Desktop columns = 1`):
  - All content is displayed in a single column.
- **Hero**: left‑ or centre‑aligned.
- **Contact CTA**: full‑width, centred.

### Tablet (768–989px)

- The two‑column layout collapses to a single column.
- The `QUESTIONS` label appears above the FAQ list (not sticky).
- Search and category navigation remain full‑width.

### Mobile (768px)

- **Single column**: all content stacks vertically.
- **Search**: full‑width with icon and clear button.
- **Category navigation**: horizontal scroll with `overflow-x: auto`.
- **Accordion**: touch‑friendly with comfortable tap targets.
- **Contact CTA**: button is full‑width for easy tapping.

## Search & Filtering

The FAQ search and category filtering work entirely on the client side:

- **Search**: filters questions, answers, and categories in real time as the user types.
- **Category navigation**: clicking a category button filters the list to show only items in that category.
- **Combine**: search and category filters work together (e.g., `Shipping` + `track`).
- **Clear**: the clear button resets the search input and restores results.
- **Result count**: live updates showing the number of visible questions.
- **Empty state**: appears when no items match the current filters.

No page reload, no Shopify search API, and no external dependencies.

## Accordion Behaviour

The FAQ accordion uses native HTML `<details>`/`<summary>` with a JavaScript enhancement:

- **Open by default**: the first item (or items marked `Open by default`) is open on page load.
- **Auto‑close**: when a new item is opened, the previously opened item is automatically closed.
- **Smooth animation**: the answer panel slides open/closed with a `max-height` and `opacity` transition (when global animations are enabled).
- **Reduced motion**: if `prefers-reduced-motion` is enabled, animations are disabled.

## Accessibility

The FAQ Page is built with accessibility as a priority:

- **Heading hierarchy** – one `<h1>` for the main heading; CTA uses `<h2>`.
- **Keyboard navigation** – all interactive elements (summary, search, category buttons) are focusable with visible focus rings.
- **Accordion** – uses native `<details>`/`<summary>`; keyboard‑accessible by default.
- **Search** – has a visible label and accessible placeholder; clear button has `aria-label`.
- **Category buttons** – use `aria-pressed` to indicate active state.
- **Live regions** – result count updates via `aria-live="polite"`; empty state is announced.
- **Focus indicators** – uses `--color-accent` with `--focus-ring-width`.
- **Reduced motion** – animations respect `prefers-reduced-motion` and the global animation setting.
- **Contrast** – all text meets WCAG contrast requirements in all three color schemes.

- **No external libraries** – all functionality is Vanilla JavaScript + CSS.
- **Client‑side filtering** – lightweight; no server requests during search.
- **Native accordion** – uses HTML `<details>`/`<summary>`; JavaScript only for auto‑close and animation.
- **CSS transitions** – smooth animations powered by CSS; minimal JavaScript.

## Troubleshooting

### The FAQ template is not available in the Theme Editor
- Ensure `templates/page.faq.json` exists in the theme.
- Create a page in Shopify Admin and assign the `faq` template to it.
- In Theme Editor, select the **FAQ** page from the dropdown.

### The accordion does not animate
- Ensure global animations are enabled (`settings.enable_animations`).
- If `prefers-reduced-motion` is enabled, animations are disabled.
- The animation uses `max-height` transition; if it's not working, check the CSS in `{% stylesheet %}`.

### Search is not filtering
- Ensure **Enable search** is on.
- The search filters against `data-faq-search` attributes on each item.
- If you add or remove blocks, the attribute is automatically updated.

### Category navigation does not appear
- Ensure **Enable category navigation** is on.
- Categories are derived from FAQ block categories; if no categories exist, the nav is hidden.
- The nav appears only if at least two categories are present.

### The result count is incorrect
- The count updates after each filter change.
- If items are hidden due to search or category, the count reflects the visible items.
- Check that each FAQ block has a non‑empty question.

### The CTA link does not work
- The link defaults to `/pages/contact` if `cta_link` is empty.
- Ensure the contact page exists in Shopify Admin.
- The link can be set to any URL via the Theme Editor.

### The two‑column layout is not showing on desktop
- Ensure **Desktop columns** is set to `2`.
- The two‑column layout applies only at ≥990px.
- The label is sticky only when `Desktop columns = 2`.

### The FAQ note is not showing
- Ensure **Enable FAQ note** is on.
- The note appears only if at least one of `Note title` or `Note text` is filled.

### The accordion opens multiple items at once
- The JavaScript auto‑close feature ensures only one item is open at a time.
- If multiple items are open, check that the JavaScript is running (`data-faq-accordion` attribute on the section).

### The page is not centred
- Use the **FAQ alignment** setting to centre the FAQ block.
- For the hero, use **Hero alignment**.
- The overall page width is controlled by the theme’s `--page-width` variable.

## Usage Examples

### Full FAQ page (with all features)
- Enable all settings.
- Add 6–10 FAQ blocks across categories (Orders, Shipping, Products, Returns, Payments).
- Enable search, category navigation, result count, and the contact CTA.
- Set **Desktop columns** to `2`.

### Minimal FAQ (no search, no categories)
- Disable **Enable search** and **Enable category navigation**.
- Disable **Show numbering** and **Show category**.
- Only the accordion with questions and answers remains.

### Centred FAQ (single column)
- Set **Desktop columns** to `1`.
- Set **Hero alignment** to `Center`.
- Set **FAQ alignment** to `Center`.
- This creates a clean, centred reading experience.

### Dark scheme with accent CTA
- Set main **Color scheme** to `Dark` (scheme-2).
- Set **CTA color scheme** to `Light + Accent` (scheme-3) for a contrasting CTA band.
