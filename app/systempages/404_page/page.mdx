# 404 Page

The **404 Page** is the not‑found experience for the COSME theme — a minimal, editorial error page that maintains the brand's premium aesthetic while helping visitors find their way back to the store. It provides clear navigation options, an optional search, and a subtle visual touch, all within the Cosme design language.

The page is built as a single section (`404.liquid`) that uses Shopify's native route helpers (`routes.all_products_collection_url`, `routes.root_url`, `routes.search_url`) and integrates with the existing Cosme design system.

![404 Page example](/img/404.png)

---

## Overview

The 404 Page provides the following key features:

- **Restrained editorial design** – large “404” eyebrow, clear heading, and brief description.
- **Primary navigation** – “Continue shopping” (to `/collections/all`) and “Back to home” (to `/`) buttons.
- **Optional search** – native Shopify search form that works without JavaScript.
- **Optional image** – subtle editorial image (off by default) with configurable aspect ratio.
- **Color schemes** – fully supports Light, Dark, and Light+Accent.
- **Subtle animation** – gentle fade‑in when global animations are enabled; respects `prefers-reduced-motion`.
- **Responsive** – adapts to all screen sizes with comfortable touch targets.

All settings are available in the Theme Editor under **Templates → 404**.

## Visual Layout

### Desktop (≥990px)

- **Centered composition**: all content is centred with generous whitespace.
- **Image (optional)**: appears above the text, centred, with configurable aspect ratio.
- **Buttons**: primary and secondary CTAs side‑by‑side.
- **Search (optional)**: appears below the buttons with inline layout (label + input + button).

### Tablet (768–989px)

- Same centred layout with slightly reduced spacing.
- Image width scaled proportionally.
- Search remains inline if space permits.

### Mobile (768px)

- **Stacked layout**: image, eyebrow, heading, description, buttons (stacked), search (stacked field + button).
- **Buttons**: full‑width for comfortable touch targets.
- **Search**: stacked email + button (inline on tablet+).
- **Typography**: scales down using `clamp()`.

## Button & Search Behaviour

- **Continue shopping** – uses `routes.all_products_collection_url` (typically `/collections/all`). Merchants can change the destination by modifying the `shop_url` variable if needed.
- **Back to home** – uses `routes.root_url` (`/`).
- **Search** – is a standard `<form>` with `method="get"` to `routes.search_url`. It includes hidden fields for `type=product` and `options[prefix]=last`. The form works without JavaScript.

---

## Animation

When global animations are enabled (`settings.enable_animations`) and the user has not set `prefers-reduced-motion`:

- The eyebrow, heading, description, buttons, search, and image fade in with a slight upward translation.
- Delays are staggered (0.06s, 0.12s, 0.18s, 0.24s) for a polished entrance.
- All animations respect `prefers-reduced-motion` and are disabled when animations are turned off.

## Accessibility

The 404 Page is built with accessibility as a priority:

- **Heading hierarchy** – exactly one `<h1>` for the main heading.
- **Semantic HTML** – uses `<main>`, `<h1>`, `<p>`, `<form>`, and buttons with appropriate semantics.
- **Button labels** – clear, meaningful labels for both CTAs.
- **Search** – has an associated visible label and proper `id`/`name` attributes.
- **Keyboard navigation** – all interactive elements are focusable with visible focus rings.
- **Focus indicators** – uses `--color-accent` with `--focus-ring-width`.
- **Color contrast** – all text meets WCAG contrast requirements in all three color schemes.
- **Reduced motion** – the animation respects `prefers-reduced-motion` and is disabled when animations are off.

## Performance

- **Minimal JavaScript** – no client‑side JavaScript required; the page is pure Liquid + CSS.
- **Eager loading** – the optional image (if used) loads eagerly (`loading="eager"`).
- **Responsive images** – uses Shopify's `image_url` with appropriate `sizes`.
- **No external libraries** – only native Shopify routes and form functionality.

## Troubleshooting

### The 404 page is not showing for unknown URLs
- Ensure the `templates/404.liquid` or `templates/404.json` exists.
- In Shopify, the 404 template is automatically used for any non‑existent path.
- Check that the theme is correctly published.

### The buttons do not navigate correctly
- **Continue shopping** uses `routes.all_products_collection_url`. If this does not exist, the button will be empty. Verify that the store has at least one collection.
- **Back to home** uses `routes.root_url`. This is always `/`.

### The search form does not work
- The form uses `method="get"` and `action="{{ routes.search_url }}"`. Ensure the store's search is enabled.
- The search input has `name="q"` and hidden fields for `type=product` and `options[prefix]=last`.
- The form works without JavaScript; if it fails, check the URL structure.

### The image is not displaying
- Ensure **Show image** is enabled.
- Select an image in the **Image** picker.
- If the image does not appear, check that the file is uploaded and accessible.

### The animation does not play
- The animation only plays when global animations are enabled (`settings.enable_animations`).
- The animation respects `prefers-reduced-motion`; if the user has this setting, the animation is disabled.
- You can force the animation to always play by removing the `prefers-reduced-motion` condition, but this is not recommended.

### The page is too tall or too short
- The section has a minimum height of `min(70svh, 46rem)` on desktop and `min(78svh, 52rem)` on tablet.
- If you need more or less vertical space, adjust the `min-height` values in the CSS.

## Usage Examples

### Minimal 404 (no image, no search)
- Disable **Show image** and **Show search**.
- Only the eyebrow, heading, description, and two CTAs appear.

### Full 404 (with image and search)
- Enable **Show image**, upload an editorial image, and choose an aspect ratio.
- Enable **Show search** and set a custom search label.
- The page will display the image, text, CTAs, and a search form.

### Dark scheme
- Set **Color scheme** to `Dark` (scheme-2) for a dramatic, high‑contrast error page.
