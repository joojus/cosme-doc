# Gift Card

The **Gift Card** page is the system template for viewing and using Shopify gift cards. It presents the gift card balance, code, and actions in a premium editorial layout that aligns with the Cosme brand — transforming a functional system page into a thoughtful, polished brand experience.

The page uses Shopify's native gift card object (`gift_card`) and preserves all core functionality: balance display, expiration status, code copying, Apple Wallet integration, and the gift card visual. It is built as a standalone template with `{% layout none %}` and does not require any merchant setup.

![Gift Card example](/img/gift-card.png)

---

## Overview

The Gift Card page provides the following key features:

- **Editorial introduction** – configurable eyebrow, heading, and description (centre‑aligned by default).
- **Two‑column layout** – gift card visual on the left, information and actions on the right (stacks on mobile).
- **Gift card visual** – features the shop name, balance, formatted code, and the native Shopify card SVG.
- **Balance display** – dynamic from `gift_card.balance | money`.
- **Status & expiration** – shows if the card is disabled or expired, and the expiration date if set.
- **Code copy** – copies the native gift card code via the Clipboard API (fallback to `execCommand`); visual feedback and live region announcement.
- **Apple Wallet** – if `gift_card.pass_url` exists, displays the native Apple Wallet add button.
- **Optional editorial message** – a configurable brand story section below the card.
- **Continue shopping** – links to the store's product collection page.
- **Color schemes** – main page and editorial section each have independent colour scheme settings.
- **Accessibility** – skip link, heading hierarchy, ARIA labels, focus states, reduced‑motion support.
- **No external dependencies** – pure Liquid + CSS + Vanilla JS.

All settings are available in the Shopify Theme Editor under **Theme settings → Gift card**.

## Visual Layout

### Desktop (≥768px)

- **Two‑column grid**:
  - **Left**: gift card visual (shop name, balance, card SVG).
  - **Right**: balance, status, expiration, formatted code, copy button, Apple Wallet (if available).
- **Intro**: centered by default, with generous spacing.
- **Editorial section**: full‑width, centred, below the main card.
- **Continue Shopping**: centred button at the bottom.

### Mobile (768px)

- **Stacked layout**: intro, visual (top), information/actions (bottom).
- Gift card visual is full‑width with `max-width: 32rem` and auto margins.
- All text scales appropriately; no horizontal overflow.

## Native Shopify Data

All dynamic data comes directly from the `gift_card` object:


| Variable | Description |
|----------|-------------|
|  gift_card.balance | money  | Remaining balance, formatted with currency. |
| ` gift_card.enabled ` | Boolean – whether the card is active. |
| `{{ gift_card.expired }}` | Boolean – whether the card has expired. |
| `{{ gift_card.expires_on }}` | Expiration date, if set. |
|  gift_card.code | format_code  | The gift card code, formatted with spaces. |
| `{{ gift_card.pass_url }}` | URL to add to Apple Wallet. |


These values are never hardcoded; they are always sourced from Shopify.

## Code Copy Functionality

- The formatted code is displayed in a `<p>` tag with `user-select: all`.
- The **Copy code** button uses the Clipboard API (`navigator.clipboard.writeText`) to copy the raw code.
- If the Clipboard API is unavailable, a fallback uses `document.execCommand('copy')`.
- On success, the button label changes to `COPIED` (via CSS `text-transform: uppercase`) and returns to `COPY CODE` after 2 seconds.
- A live region (`role="status"`) announces the copy result for screen readers.
- The code remains selectable even without JavaScript.

## How to Preview

Because the Gift Card is a system page, it cannot be accessed via a regular storefront URL. To preview it:

1. **Theme Editor**: In Customize, select **Templates → Gift card** from the dropdown.
2. **Shopify Admin**: Create a test gift card (Products → Gift cards) and use the preview link.
3. **Local development**: With `shopify theme dev`, press `g` in the terminal or visit the special preview URL (e.g., `http://127.0.0.1:9292/gift_cards/[store_id]/preview`).

## Troubleshooting

### The gift card visual does not show
- Ensure the `gift_card` object is passed to the snippet.
- The card uses `{{ 'gift-card/card.svg' | shopify_asset_url }}` – this is a Shopify‑provided asset.

### The balance is not formatted correctly
- The balance uses `{{ gift_card.balance | money }}` – this respects the store's currency settings.

### The copy button does not work
- Check that the button has the `data-code` attribute with the raw code.
- If the Clipboard API is blocked, the fallback `execCommand` is used.
- Ensure the button is not disabled.

### The Apple Wallet button does not appear
- Apple Wallet is shown only when `gift_card.pass_url` is present (Shopify provides this for eligible cards).

### The expired/disabled status is not shown
- The status is shown when `gift_card.enabled == false` or `gift_card.expired` is true.
- If neither condition is met, the status block is hidden.

### The editorial section is not visible
- Enable **Show editorial message** in Theme Settings.
- Fill in at least one of the editorial fields (eyebrow, heading, or text).

### The page does not respect the colour scheme
- The main page uses `settings.gift_card_color_scheme`.
- The editorial section uses `settings.gift_card_editorial_color_scheme`.
- If these settings are empty, they fall back to the global `settings.color_scheme`.

### The layout is broken on mobile
- The grid uses `grid-template-columns: 1fr` on mobile and switches to `1fr 1fr` at `768px`.
- Check that no custom CSS overrides these values.

## Usage Examples

### Full editorial gift card (default)
- Enable all settings.
- Use the default copy for intro and editorial.
- Light scheme for main page, Light+Accent for editorial (if desired).

### Minimal gift card (no editorial message)
- Disable **Show editorial message**.
- The page will show only the intro, gift card, actions, and Continue Shopping.

### Brand‑focused gift card
- Customise the heading, description, and editorial text to match your brand voice.
- Set the editorial colour scheme to `Dark` for contrast.
