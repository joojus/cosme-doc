# General settings

In Cosme theme, you can find some general settings that are available in all building block sections.

## Color scheme

Apply a color scheme to the section.&#x20;

To define a set of default color schemes for your store, go to **Theme settings >** [**Colors**](/colors).

![image](/img/image_1IJP4cOA.png)

## Section padding

Toggle the slider to adjust the top and bottom padding of the section.

![image](/img/image_td5BO7pC.png)

## Section divider

This divider line provides a clear boundary between the current section and the above.

To activate the divider line, enable the ✅ **Show divider** checkbox.&#x20;

Choose a suitable **Divider width** for the divider: Fixed width/ Full width.

![image](/img/image_pBPfEqvW.png)

## Highlight text

You can use the Underline effect option for the **Highlighted text** (Select None if you want this text to display in italic style only).

<Callout type="info">

To add an animated highlight to the text, simply wrap it in italics. Click the "I" button in the editor to toggle italics when highlighting text.

![](/img/image_TK9ZiMFU.png)         
</Callout>

<Callout type="warning">

**Note**: This highlighted text only applies to certain **section headings** and **block headings**.

</Callout>

![image](/img/image_9KOMvVrc.png)
